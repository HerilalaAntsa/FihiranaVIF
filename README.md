# Fihirana VIF

**Application Web & Mobile pour les paroles de chansons VIF**

---

## 🌟 À propos

Fihirana VIF est une application web et mobile qui permet d’accéder aux paroles des chansons de l’église VIF.  
L’objectif est de fournir une interface simple, rapide et intuitive pour consulter, rechercher et naviguer dans le répertoire des chansons.

---

## ⚙️ Fonctionnalités

- Affichage complet des chansons avec paroles  
- Recherche par titre ou auteur  
- Catégorisation des chansons  
- Interface responsive pour web et mobile  
- Gestion facile des contenus pour les administrateurs  

---

## 🛠️ Stack technologique

- **Frontend** : React  
- **Backend** : Node.js, Express  
- **Base de données** : MongoDB  
- **API** : REST  
- **Tests** : Jest
